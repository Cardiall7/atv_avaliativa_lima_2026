# Projeto Sobrenatural

Este é um site informativo sobre a série **Supernatural**, criado como um projeto escolar.

## Sobre o site
- Ele mostra um breve resumo sobre a serie sobrenatural de 2005, ele conta sobre os elencos, curiosidades e no final so site tem um formulario, para você responder curisidades sobre o site.

## Tecnologias
* HTML5 (Estrutura)
* CSS3 (Estilo e Efeitos)

## Como rodar o projeto
Para o site e os efeitos funcionarem direitinho, abra o arquivo `index.html` usando a extensão **Live Server** do VS Code.
